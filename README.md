# volume-control-project

A system that can accept hand movement in real time is hand gesture recognition. The design of hand gesture recognition is quite difficult, as it combines two main problems. The detection of the hand is the first step in creating a sign that can only be manoeuvre by one hand at a time. 


The primary goal of this gesture recognition project is to develop a system that can recognize specific human hand gestures and make use of them to send information to the device to control the volume of the system. With this method, a user can operate a system by making some specific gesture in front of its camera. With the help of the Open CV, MEDIAPIPE AND PYAUTOGUI modules, we will create a volume control by hand gestures. Without the use of a keyboard or mouse, the computer’s volume can be controlled via hand gestures.


Hand gesture detection helps computers to understand human body sign language. This helps to build a pathway between humans and computers, rather than just the basic texts. In this report for hand gesture detection, the human body’s movements are read by a systems camera. The main objective of this project is to develop a communication which will capture hand gestures dynamically and control the volume level through it.

Open CV: - Open CV is a library of python. It is used in various projects to detect the hand and face and is also used in other programming languages. OpenCV is a large open-source library for the computer, image processing etc. By using this, one can process images, videos and even the handwriting of a human being. 


Pyautogui:- On Windows, Pyautogui accesses the window to give output through the built-in modules.


Mediapipe:- It is an open-source library, which has some solutions for hand gesture detection and recognition and provides a summarization of python. MediaPipe Hands is a high-precision hand-tracking solution. It uses ML to infer 21 key 3D hand information from just a single frame. We can use it to extract the co-ordinates of the given key points of any hand.
